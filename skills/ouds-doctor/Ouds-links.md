# OUDS redirection links

Index of the short links pointing to Orange Unified Design System (OUDS) resources. Each component lists one link per destination.

## How to read this file

- **DSM**: component documentation page on the OUDS design system manager.
- **DSM Changelog**: changelog of the component documentation.
- **Design**: design page of the component.
- **Web / Android / iOS / Flutter**: developer documentation of the component in each platform library.
- `Not applicable`: the component does not exist on that platform (NA in the source).
- `Not available`: no link yet.
- `⚠️ Temporary`: temporary link to the component list until the documentation is released.
- `(centralized in Badge)`: no dedicated page; this content is centralized in the Badge developer documentation for that platform.
