# OUDS redirection links

Index of the short links pointing to Orange Unified Design System (OUDS) resources. Each component lists one link per destination.

## How to read this file

- **category**: category of the component on the OUDS Hub (Action, Content display, Control, Dialog, Indicator, Layout, Navigation).
- **family**: group of related components inside the category, as on the OUDS Hub (for example the Button family: Assistant button, Button, Expand button, Navigation button, Social button). `None`: the component is not part of a family.
- **OUDS Hub**: component documentation page on the OUDS Hub (zeroheight).
- **OUDS Hub Changelog**: changelog of the component documentation.
- **md documentation**: full Markdown description of the component in the ouds-documentation GitHub repository.
- **Design**: design page of the component.
- **Web / Android / iOS / Flutter**: developer documentation of the component in each platform library.
- `Not applicable`: the component does not exist on that platform (NA in the source).
- `Not available`: no link yet.
- `⚠️ Temporary`: temporary link to the component list until the documentation is released.
- **Short links and their destination** (`oran.ge`, `r.orange.fr`): a short link is written first, then its destination after ` -> `, as `shortLink -> full link`. Use the short link when communicating a link (it is the one to share and to show); the full link is the page it leads to today, so that an AI knows the destination. A short link without ` -> ` has no destination recorded yet. When a redirection changes, update the full link, never the short link.
- **Other redirections**: the other OUDS resources, sorted by need in sections. A line may add, after `—`, what the link is for, then its audience and access in brackets.
