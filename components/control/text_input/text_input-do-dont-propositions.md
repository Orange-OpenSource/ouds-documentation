# Text input — do & don't propositions

AI-generated propositions that no one has validated yet. They are not part of the documentation ([text_input.md](text_input.md)) and are not shown on zeroheight. Once a designer validates one, it moves into the full file.

## When to use

✅ To capture short, single-line text input

✅ In forms, dialogs, and search interfaces requiring quick and precise entry

✅ When the value has a defined format or limited length

✅ For data that can be entered and validated inline
