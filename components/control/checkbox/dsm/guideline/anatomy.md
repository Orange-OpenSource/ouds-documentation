| # | Element | Purpose | Optional |
|---|---------|---------|----------|
| 1 | Checkbox indicator | Visually indicates the state of the checkbox (unchecked, checked, indeterminate). Unchecked by default. | N |
| 2 | Label | Primary text that describes the selectable option. Should be short and easy to scan. | N |
| 3 | Description | Optional supporting text that provides additional context or instructions for the option. | Y |
| 4 | Icon | Optional decorative or functional icon used to visually reinforce the meaning of the option. | Y |
| 5 | Divider | Separator line used when multiple checkbox items are grouped together. | Y |
| 6 | Error text | Text message explaining why the field is in an error state. Displayed when validation fails. | Y |
| 7 | Error icon | Visual indicator that highlights the error state of the component. | N |
