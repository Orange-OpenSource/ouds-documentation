### Structure & Labels

- [ ] **Reading order**: The tag is placed in the DOM next to the content it describes, so it is announced with it
- [ ] **Decorative marker**: The bullet and a decorative icon are hidden from assistive technologies ([Orange ARIA guidelines](https://a11y-guidelines.orange.com/en/web/develop/textual-content/))
- [ ] **Loading state**: A text alternative such as "Loading" is provided while the indicator is displayed

### Visual Design

- [ ] **Text contrast**: Label text meets 4.5:1 against each of the five categorical colours
- [ ] **Not colour alone**: Categories that must be distinguished have different labels, not only different colours
- [ ] **Zoom**: At 200% text size the tag grows and wraps without clipping the label

### Content

- [ ] **Concise labels**: ❌ "This product is part of our refurbished range" / ✅ "Refurbished" ([Clear labels](https://a11y-guidelines.orange.com/en/web/design/content/))
- [ ] **Stable meaning**: A colour slot keeps the same category within the same context
