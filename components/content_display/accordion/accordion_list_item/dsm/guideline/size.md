**`Default`** Use the Default size in most interfaces.
It provides sufficient spacing for standard accordion lists, multiline labels and visual elements.

**`Small`** Use the Small size in compact layouts where information density is important.

The Small size is best suited to:
• Short labels.
• Simple supporting information.
• Compact desktop accordion lists.

⚠️ Do not mix Default and Small items within the same continuous accordion unless they represent clearly different sections or levels of hierarchy.
