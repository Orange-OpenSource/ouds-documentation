**Size**
Controls the visual prominence of the icon.

⚠️ Use the same icon size for equivalent items within the same accordion. Do not mix sizes arbitrarily. Different sizes may suggest a hierarchy or importance that does not exist.

**`Medium`** Use for standard and compact accordion items. This is the preferred size when the icon provides secondary visual support.

**`Large`** Use when the icon needs stronger prominence or when the item has a larger height, multiline content or additional supporting information.
