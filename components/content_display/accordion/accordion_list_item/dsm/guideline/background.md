**`False`** The accordion item uses the surrounding container surface without an individual background. Use this option for standard continuous accordion lists.

**`True`** A Background is applied to the accordion trigger.  
Use it when an item needs stronger visual separation from the surrounding content or when accordion sections are presented as distinct grouped elements.

⚠️ Use the same background treatment for equivalent items within the same accordion. Avoid using Background only to make one section appear more important.
