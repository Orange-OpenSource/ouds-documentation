**`False`** Use False as the standard layout. The Expanding indicator is displayed at the logical end of the trigger, after the main content and any optional Trailing content.

True
Use Reverse when the Expanding indicator needs to appear at the logical start of the trigger. The indicator is positioned before the main content.

⚠️ Keep the same indicator position for equivalent items within the same accordion. Do not alternate between standard and reversed layouts only for visual variety.
