- **2.1.2 No Keyboard Trap** (A): Focus stays inside the open sheet but users can always leave it with the keyboard

- **2.4.11 Focus Not Obscured (Minimum)** (AA): The focused element is never fully hidden by sticky actions or the sheet edges
