The “iOS bars” component family groups all native mobile navigation components used to structure and orient the user within an application.

It includes platform-specific patterns for iOS, such as Tab Bar, Toolbar top, Toolbar bottom, Status bar, and other system-level navigational UI elements.

This family provides the foundational structures that enable users to move across primary sections, access key actions, understand their current location in the app, and interact with the operating system’s native navigation paradigms.
