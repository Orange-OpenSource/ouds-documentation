## TJ (southleft)

Auteur de la newsletter "Slot Machine" (southleft.substack.com), liée à [southleft](https://github.com/southleft), l'organisation également derrière le serveur MCP open source pour design systems documenté dans [design-systems-mcp-complete-guide](../sources/design-systems-mcp-complete-guide.md). Dans [anatomy-ai-ready-design-system-southleft](../sources/anatomy-ai-ready-design-system-southleft.md) (mai 2026), TJ documente un atelier avec une équipe design system enterprise sans accès aux outils IA, et défend la thèse que les pratiques rendant un design system AI-ready sont les mêmes que celles qui le rendent lisible pour des humains, un vocabulaire différent de [geri-reid](geri-reid.md) pour une thèse convergente.
